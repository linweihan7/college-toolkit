Account & Cloud Sync

Sync your data to the cloud so it follows you across devices. Works fully offline and logged out — sync is a bonus, not a requirement.

Canvas Sync

In Canvas, go to Calendar → Calendar Feed, copy the link, and paste it here. Your assignments and class times will fill in automatically. The feed URL contains a private token — treat it like a password.

AI Quick Capture

Press ⌘K and type things like “coffee 6.50” or “econ midterm next thursday 2pm” — they land in the right tab automatically. Built-in parsing is free; adding a Claude API key makes it smarter. The key stays in this browser only and is never included in backups.

Notifications

Alerts for assignments & tasks due today and classes starting soon, while the app is open. On iPhone: open this site in Safari, tap Share → Add to Home Screen, then enable here (iOS 16.4+). Closed-app push isn't possible without a server yet.

Data & Backup

Everything you add saves automatically to this browser and is never deleted unless you delete it yourself. Download a backup file anytime for extra safety, or restore one below.
